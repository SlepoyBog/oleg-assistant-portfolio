# ADR 0001: рабочие источники подключаются только для чтения

- Статус: принято
- Дата: 2026-09-21

## Контекст

Рабочая база уже содержит зрелые документы, расчётные таблицы и отдельные системы. Импорт этих данных в SQLite помощника создаст дубликаты, риск рассинхронизации и возможность принять расчётные параметры за утверждённые.

## Решение

Oleg Assistant читает рабочую базу через отдельные адаптеры. Корень задаётся `WORK_ROOT`. Если путь или источник недоступен, функция завершается безопасным сообщением. Первая интеграция показывает оперативный статус и ничего не записывает в рабочую базу.

## Последствия

- Существующие документы и системы остаются источниками истины.
- Бот может показывать статус, не меняя рабочие файлы.
- Любая будущая запись в рабочую базу потребует отдельного решения и явного согласования.
