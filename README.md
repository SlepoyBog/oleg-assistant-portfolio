# Oleg Assistant

Личный Telegram-помощник для планирования рабочего дня и ведения локальной базы задач. Работает на Windows, хранит данные локально и принимает команды только от привязанного владельца в личном чате.

Проект вырос из реального производственного процесса: ежедневный план раньше составлялся вручную около часа, теперь задачи фиксируются в Telegram по мере появления, а бот формирует постоянный Excel-план для руководителя. Рабочие данные, токены и внутренняя структура предприятия в репозиторий не входят.

## Возможности

- входящие записи с подтверждением типа;
- заметки, задачи, события, идеи, категории и поиск;
- план на сегодня, завтра и ближайшие семь дней;
- автоматический Excel-план на рабочую неделю 08:00–17:00 с обедом 12:30–13:30;
- запрос длительности новой задачи и подбор ближайшего свободного времени;
- ручной перенос задачи в нижней таблице Excel с возможностью закрепить время;
- один постоянный файл плана с архивированием предыдущей версии перед обновлением;
- пошаговое меню Telegram;
- карточки деталей и станков;
- приход, расход, остатки и минимальный запас;
- история движения расходников и быстрые кнопки изменения остатка;
- выполнение и подтверждённое удаление задач;
- локальный экспорт памяти и склада в Excel;
- локальные резервные копии;
- автозапуск и автоматическое восстановление после сбоя;
- работа основных функций без расхода лимита ИИ.

План развития находится в ROADMAP.md.

## Примеры

~~~text
план
нужно проверить шум станка завтра
событие: встреча в четверг в 10:00
заметка: поставщик работает по предоплате
идея: поставить датчик вибрации
входящие
план excel
~~~

После создания задачи бот предложит длительность: 15, 30, 45, 60, 90 или 120 минут. После выбора задача попадёт в ближайшее свободное время рабочего дня.

В файле плана вручную меняются жёлтые столбцы `Дата`, `Начало`, `Длительность, мин` и `Закреплено`. Значение `Да` фиксирует назначение. При следующем обновлении бот сначала прочитает эти правки, затем перестроит недельную сетку. Строки задач нельзя добавлять вручную без ID — новую задачу нужно отправить боту.

Если файл открыт в Excel и недоступен для записи, база остаётся актуальной, а бот повторит обновление файла позже.

~~~text
запомни размер тары 1140х740
нужно купить защитные стекла
найди тара
готово 3
~~~

Карточка:

~~~text
карточка детали Корпус 150_125; станок=Longxin T28; материал=09Г2С; толщина=8 мм
покажи карточку Корпус 150_125
~~~

Склад:

~~~text
приход 20 | защитное стекло
расход 2 | защитное стекло | Longxin T28
минимум 5 | защитное стекло
остатки
история защитное стекло
экспорт excel
~~~

Эти действия также доступны через кнопочное меню /menu.

## Установка на Windows

1. Установите Python 3.11 или новее.
2. Скопируйте .env.example в .env.
3. Впишите токен Telegram-бота и код первичной привязки.
4. Установите зависимости:

~~~powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
~~~

5. Запустите:

~~~powershell
powershell -ExecutionPolicy Bypass -File .\run_bot.ps1
~~~

6. В Telegram выполните /claim ваш_код.

## Данные и безопасность

Локальные данные находятся в data/assistant.db. Excel-экспорты создаются в exports/. Файлы .env, база, журналы, экспорты, резервные копии, виртуальное окружение и рабочие документы исключены из Git.

Репозиторий подготовлен для публичного просмотра на демонстрационных настройках. Не добавляйте токен, рабочие базы, внутренние документы, реальные производственные пути или персональные данные в исходный код, сообщения коммитов и задачи GitHub.
